# number_guessing_game_using_python
It is a simple number guessing game using python.In which the computer itself randomly choose one number in which we had to guess that number if the number which we guesses is corrrect then it congratulates us 
if the number which we had to guess is lower than the number which we are guessed then it gives a message that our number is too high
if the number which we had to guess is higher than the number which we are guessed then it gives a message that our number is too low
like this it carry us towards the answer side 


we can play this game like we can compete with the friends that who can guess the number correctly
also group of friends can guess individually and compare the no.of attempts and who can guess the number in less no.of attempts that person is the winner
